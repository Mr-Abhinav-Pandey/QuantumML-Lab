# Original experiments — QuantumML Lab

This directory is reserved exclusively for data generated by running this project's own code.

- `configurations/`: exact settings for each run.
- `results/`: output metrics and generated data.

Each run must have a unique experiment ID, timestamp, random seed, configuration, code/version identifier where available, and source label `ORIGINAL_EXPERIMENT`.

Do not copy published values into this directory. Do not store literature summaries here. A run may be labelled `REPRODUCED_REFERENCE_RESULT` only after its setup has been checked against the relevant paper and the reproduction has actually been executed.

The starter application currently performs a small two-qubit VQC classification demonstration. It does **not** yet implement a full barren-plateau reproduction. Do not describe its current classifier results as a barren-plateau study.
