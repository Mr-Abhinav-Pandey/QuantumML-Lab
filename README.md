# QuantumML Lab

An undergraduate PBL project: **Design and Development of a Quantum Machine Learning Framework Using Variational Quantum Circuits for Binary Classification**.

This is a local software-only application. It implements a genuine two-qubit statevector variational quantum classifier (VQC) using NumPy, with a parameter-shift training rule, an interactive Streamlit interface, and a classical neural-network baseline.

## Requirements
- Windows 10/11
- Python 3.10–3.12 recommended
- Internet connection for the initial Python package installation only

## Run on Windows
Open Command Prompt in this folder and run:

```bat
py -m venv .venv
.venv\Scripts\activate
py -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

Streamlit will print a local address, normally `http://localhost:8501`.

## Features
- Two-qubit statevector simulator
- Angle encoding using RY rotations
- Trainable RY/RZ gates and CNOT entanglement
- Binary classification on two-moons, concentric-circles and linearly separable datasets
- Parameter-shift gradient training
- Classical MLP baseline
- Circuit parameter and measurement-probability inspection
- Ideal and finite-shot measurement modes
- Training curves and confusion matrix

## Mathematical model
For each input, two features are angle encoded as `RY(pi*x0)` and `RY(pi*x1)`. Each variational layer applies trainable RY and RZ rotations to both qubits followed by CNOT. The output is the expectation value of Pauli-Z on qubit 0, converted into a class probability:

`p(class 1 | x) = (1 - <Z0>) / 2`.

The loss is binary cross entropy. Gradients for the trainable rotation parameters are calculated using the parameter-shift rule.

## Important scientific scope
The application simulates a quantum circuit on a classical computer. It is not a physical quantum processor, does not demonstrate quantum advantage, and does not establish that a VQC is better than classical machine learning. The finite-shot option samples the model's output probabilities but is not a full hardware noise model.

## Suggested experiments for the report
1. Compare the VQC and classical MLP on all three datasets.
2. Vary the number of variational layers and compare accuracy and training loss.
3. Vary dataset noise and measure the change in test accuracy.
4. Compare ideal expectation values with finite-shot approximations at different shot counts.
5. Discuss training stability, parameter count, circuit depth and limitations of small-scale VQCs.

## Separate published references from original experiments

The project now maintains two intentionally separate research areas:

- `research/reference_library/`: bibliographic metadata and study notes for published work. These records are marked as published references and are not generated by this project.
- `research/original_experiments/`: configurations and result records generated by running this application. Each run receives an `EXP-...` identifier and the source label `ORIGINAL_EXPERIMENT`.

The Streamlit interface includes separate **Research references** and **Our experiment record** tabs. Do not describe the starter VQC classification run as a reproduction of a barren-plateau paper. The included papers are study references; a paper-specific reproduction requires matching that paper's assumptions, ansatz, observable, initialization, system sizes and gradient definition.

### Core references included

- McClean et al. (2018), *Barren plateaus in quantum neural network training landscapes*, DOI: 10.1038/s41467-018-07090-4.
- Cerezo et al. (2021), *Cost function dependent barren plateaus in shallow parametrized quantum circuits*, DOI: 10.1038/s41467-021-21728-w.
- Ragone et al. (2024), *A Lie algebraic theory of barren plateaus for deep parameterized quantum circuits*, DOI: 10.1038/s41467-024-49909-3.
- Cunningham & Zhuang (2025), *Investigating and mitigating barren plateaus in variational quantum circuits: a survey*, DOI: 10.1007/s11128-025-04665-1.
